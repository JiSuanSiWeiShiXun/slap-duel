# 公开仓库边界

本仓库首次发布为独立源码快照，保留游戏、测试、构建工具、资源引用和公开开发文档。此前私人工作历史未上传。

私人规划、会议/试玩原话、Notion 页面及回执、预览二维码、工具截图、主机配置和账号身份不属于公开内容。它们通过忽略规则留在本地。真实微信身份使用环境变量或被忽略的本机配置。

提交前执行 `node tools/check-public-tree.mjs`。该检查核对跟踪路径、常见令牌/私钥格式、个人主目录、账号身份及私人链接；失败仅报告文件和类别，不输出疑似秘密值。检查通过不能替代人工审查新增二进制或新类型配置。

推送应明确指定公开分支，例如 `git push origin main`。不要从保留私人历史的本地仓库执行 `--all`、`--mirror` 或推送私人标签。
