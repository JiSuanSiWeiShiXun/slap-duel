# 架构与当前边界

规则接收显式时间和动作，输出状态与语义事件。它不依赖 Cocos、网络或音效；相同初态及带时间戳的动作应得到相同结果。

`InputBridge` 将触摸映射为动作，`LocalSession` 管理暂停、重开和机器人。机器人经同一规则入口出手，不能直接扣血。表现消费状态与事件，不能用动画回调裁定命中。反馈事件按 ID 去重。

当前有开始、模式选择、练习、战斗、暂停、放弃确认、结算和重试。生命、伤害、前摇、防御窗口、恢复及局时集中在 `DEFAULT_RULES`。普通点击和未满蓄力伤害 1，满 1200ms 伤害 2；界面明确显示蓄力状态及实际命中数字。

后续方向是先完成单机正式美术、动作、音画与手感，再复用规则和表现实现真人匹配。当前没有联机后端、房间、账号体系或网络同步。静态 Web 站点上线只提供单机试玩。

当前已运行过 Web 和微信开发者工具构建，逻辑与工具测试已有通过记录。真实触摸取消、后台恢复和正式单机体验仍有待验项；公开源码或编译成功不构成全部游戏验收。
